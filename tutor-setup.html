    Dev Setup — Cài đặt Tutor Open edX từ đầu

    Lộ trình ít lỗi nhất cho Ubuntu (WSL2 tương tự): dùng virtualenv, kiểm tra Docker, cấu hình hosts, launch Local, chạy migrations, tạo admin, bật Dev (build openedx-dev) & chèn kỳ vọng hiển thị sau mỗi bước.

    1) Yêu cầu hệ thống

    docker --version
docker compose version
python3 --version
sudo apt update && sudo apt install -y python3-venv python3-pip
    Kỳ vọng hiển thị: 
    Docker version 2x.x.x, build ...
Docker Compose version v2.x.x
Python 3.11.x
...
    Lưu ý: Nếu từng bị getcwd() failed, hãy cd ~ trước khi cài đặt.

    2) Tạo virtualenv & cài Tutor (ổn định nhất)

    # Tạo venv riêng cho Tutor
python3 -m venv ~/.venvs/tutor-20
~/.venvs/tutor-20/bin/pip install -U pip

# Cài đúng bản Indigo 20.0.1
~/.venvs/tutor-20/bin/pip install "tutor[full]==20.0.1"

# Tiện alias (zsh/bash)
echo 'alias tutor="$HOME/.venvs/tutor-20/bin/tutor"' >> ~/.zshrc 2>/dev/null || true
echo 'alias tutor="$HOME/.venvs/tutor-20/bin/tutor"' >> ~/.bashrc 2>/dev/null || true
source ~/.zshrc 2>/dev/null || source ~/.bashrc 2>/dev/null || true

# Kiểm tra
tutor --version
    Kỳ vọng hiển thị: 
    20.0.1

    3) Cấu hình nền tảng & map hosts

    tutor config save \
  --set OPENEDX_LMS_BASE=local.openedx.io \
  --set OPENEDX_CMS_BASE=studio.local.openedx.io \
  --set PLATFORM_NAME="My Open edX" \
  --set CONTACT_EMAIL="admin@local.openedx.io"

# Map hosts nếu chưa có
grep -q local.openedx.io /etc/hosts || \
  echo -e "127.0.0.1 local.openedx.io\n127.0.0.1 studio.local.openedx.io" | sudo tee -a /etc/hosts
    Kỳ vọng hiển thị: 
    Configuration saved to /home/<user>/.local/share/tutor/config.yml
Environment generated in /home/<user>/.local/share/tutor/env
127.0.0.1 local.openedx.io
127.0.0.1 studio.local.openedx.io

    4) Khởi tạo Local & chạy nền

    # Launch (tạo env, kéo images, init DB)
tutor local launch

# Chạy nền & kiểm tra
tutor local start -d
tutor local status
tutor local logs --tail=120 lms
tutor local logs --tail=120 cms
    Kỳ vọng hiển thị: 
    The platform is now running and can be accessed at:
  http://local.openedx.io
  http://studio.local.openedx.io
  http://meilisearch.local.openedx.io
  http://apps.local.openedx.io

    5) Chạy migrations (khi thiếu bảng)

    Nếu gặp lỗi như ProgrammingError: (1146, "Table 'openedx.waffle_switch' doesn't exist"), chạy:

    tutor local run lms ./manage.py lms migrate --noinput
tutor local run cms ./manage.py cms migrate --noinput

# Xem migrations đã apply
tutor local run lms ./manage.py lms showmigrations | tail -n 60
tutor local run cms ./manage.py cms showmigrations | tail -n 60
    Kỳ vọng hiển thị: 
    waffle
 [X] 0001_initial
 [X] 0002_auto_20161201_0958
...

    6) Tạo tài khoản admin & đặt mật khẩu

    # Tạo superuser
tutor local do createuser --staff --superuser admin admin@local.openedx.io

# Đặt mật khẩu
tutor local run lms ./manage.py lms shell -c "
from django.contrib.auth import get_user_model
u=get_user_model().objects.get(username='admin')
u.set_password('123'); u.save(); print('OK')
"
    Kỳ vọng hiển thị: 
    OK

    7) Truy cập thử

    • LMS: http://local.openedx.io
    • Studio: http://studio.local.openedx.io

    8) Bật môi trường Dev (tutor dev)

    Dev dùng image openedx-dev build tại chỗ. Nếu xóa image trước đó, cần build lại.

    # Build image dev
tutor images build openedx-dev

# (tuỳ chọn) kiểm tra image dev
tutor config printvalue DOCKER_IMAGE_OPENEDX_DEV
docker image ls | grep openedx-dev

# Start dev
tutor dev start
    Kỳ vọng hiển thị: 
    [+] Running ...
 ✔ lms, cms, watchthemes ... Started
    Lỗi phổ biến: pull access denied for openedx-dev ⇒ Chưa build image dev. Chạy tutor images build openedx-dev rồi tutor dev start.

    8.1) Migrations, superuser & logs trong Dev

    # Migrate trong dev
tutor dev run lms ./manage.py lms migrate --noinput
tutor dev run cms ./manage.py cms migrate --noinput

# Tạo/đổi mật khẩu admin trong dev
tutor dev run lms ./manage.py lms createsuperuser
tutor dev run lms ./manage.py lms changepassword admin

# Logs
tutor dev logs --tail=200 lms
tutor dev logs --tail=200 cms

    9) (Tuỳ chọn) Sửa lỗi MySQL “Access denied” nhanh

    Nếu user openedx trong MySQL lệch mật khẩu với cấu hình Tutor:

    OPENEDX_MYSQL_PASSWORD=$(tutor config printvalue OPENEDX_MYSQL_PASSWORD)
MYSQL_ROOT_PASSWORD=$(tutor config printvalue MYSQL_ROOT_PASSWORD)
OPENEDX_DB=$(tutor config printvalue OPENEDX_MYSQL_DATABASE 2>/dev/null || echo openedx)

read -r -d '' SQL <<'EOF'
CREATE DATABASE IF NOT EXISTS `%OPENEDX_DB%` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'openedx'@'%' IDENTIFIED BY '%OPENEDX_MYSQL_PASSWORD%';
ALTER USER 'openedx'@'%' IDENTIFIED BY '%OPENEDX_MYSQL_PASSWORD%';
GRANT ALL PRIVILEGES ON `%OPENEDX_DB%`.* TO 'openedx'@'%';
FLUSH PRIVILEGES;
SELECT user,host,plugin FROM mysql.user WHERE user='openedx';
EOF
SQL=${SQL//%OPENEDX_DB%/$OPENEDX_DB}
SQL=${SQL//%OPENEDX_MYSQL_PASSWORD%/$OPENEDX_MYSQL_PASSWORD}
echo "$SQL" | tutor local exec -T mysql sh -lc 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -h127.0.0.1'
    Kỳ vọng hiển thị: 
    user    host    plugin
openedx %       caching_sha2_password

    10) (Phụ lục) Xóa sạch để làm lại từ đầu

    tutor dev stop || true
tutor local stop || true

# Down & xoá volumes
docker compose -f ~/.local/share/tutor/env/local/docker-compose.yml \
  -f ~/.local/share/tutor/env/local/docker-compose.prod.yml \
  -f ~/.local/share/tutor/env/local/docker-compose.jobs.yml \
  --project-name tutor_local down -v --remove-orphans || true

docker compose -f ~/.local/share/tutor/env/local/docker-compose.yml \
  -f ~/.local/share/tutor/env/dev/docker-compose.yml \
  --project-name tutor_dev down -v --remove-orphans || true

# Xoá data/env/build
sudo chown -R "$USER":"$USER" ~/.local/share/tutor || true
chmod -R u+rwX ~/.local/share/tutor || true
rm -rf ~/.local/share/tutor/data ~/.local/share/tutor/env ~/.local/share/tutor/build
rm -f  ~/.local/share/tutor/config.yml

# Xoá images chính (tuỳ chọn)
docker image ls | awk '/overhangio\\/openedx|openedx-dev|overhangio\\/openedx-mfe|mysql|mongo|redis|caddy/ {print $3}' | xargs -r docker rmi -f

docker system prune -f
