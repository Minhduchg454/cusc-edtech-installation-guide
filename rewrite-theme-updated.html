Đang xem: rewrite-theme


    DEV THEME — Hướng dẫn thiết lập & áp dụng theme trong Tutor

    Tài liệu này giữ nguyên giao diện/UX của bản gốc, nhưng nội dung đã được rút gọn theo checklist bạn cung cấp để thao tác nhanh khi phát triển theme trong môi trường tutor dev.

    Yêu cầu

    • Đã cài môi trường phát triển Tutor.
    • Đã cài phần mềm quản lý file nautilus trên Ubuntu.
    • Đã cài phầm mềm editor subline text trên Ubuntu.

    Setup khung sườn

    Đi tới thư mục themes của Open edX trong Tutor:

    cd $(tutor config printroot)/env/build/openedx/themes
    Mẹo (tuỳ chọn): Cài nautilus để mở giao diện quản lý file rồi chạy: 
    nautilus .

    Kiểm tra xem có thư mục indigo hay chưa.

    Trường hợp đã có indigo:

    1. Chuột phải trong cửa sổ thư mục và chọn New Folder (hoặc nhấn Shift + Ctrl + N).
    2. Đặt tên thư mục mới (đây chính là tên theme của bạn).
    3. Mở thư mục indigo, copy các thư mục con của nó: cms, lms, tasks.
    4. Dán những thư mục vừa copy vào thư mục theme mới tạo ở bước 2.

    Trường hợp chưa có indigo:

    1. Nếu chưa ở sẵn trong thư mục themes thì chạy: 
      cd $(tutor config printroot)/env/build/openedx/themes
    2. Clone repo theme mẫu từ GitHub: 
      git clone https://github.com/NekoNeko6996/tutor-edx-mytheme.git

    Dev mount thẳng thư mục build của Tutor

    Tạo (hoặc sửa):

    subl ~/.local/share/tutor/env/dev/docker-compose.override.yml

    Thêm (hoặc sửa) đoạn sau trong file yml:

    services:
  lms:
    volumes:
      - ~/.local/share/tutor/env/build/openedx/themes:/openedx/themes:rw
  cms:
    volumes:
      - ~/.local/share/tutor/env/build/openedx/themes:/openedx/themes:rw

    Set theme của tutor dev sang tutor-edx-mytheme

    tutor config save --set LMS_SITE_THEME=tutor-edx-mytheme --set CMS_SITE_THEME=tutor-edx-mytheme

    Kiểm tra:

    tutor config printvalue LMS_SITE_THEME
    Kỳ vọng: 
    tutor-edx-mytheme

    Set theme trực tiếp:

    tutor dev do settheme tutor-edx-mytheme

    Chạy Tutor (Dev)

    Khởi động môi trường phát triển:

    tutor dev start
    Lưu ý: Sau khi set theme, nếu bạn điều chỉnh CSS/SCSS, hãy dùng tutor dev run watchthemes để tự động biên dịch giao diện.
