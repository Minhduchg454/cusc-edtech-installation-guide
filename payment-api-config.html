Đang xem: cusc-edx-api


    Hướng dẫn tích hợp plugin cusc_edx_api với Open edX (Dev & Production)

    1) Mục tiêu

    cusc_edx_api bổ sung API REST cho LMS (user lookup, tạo/cập nhật order, auto‑enroll) và lệnh dọn order pending lâu; cho phép một dịch vụ thanh toán bên ngoài (Node.js) tương tác an toàn với Open edX.

    • Tạo order ở LMS, cập nhật trạng thái thanh toán, và enroll user sau khi paid.
    • Có lệnh cleanup_cusc_orders để expire/xóa order pending quá lâu.
    Repo tham khảo: https://github.com/NekoNeko6996/cusc_edx_api

    2) Cấu trúc chung của plugin

    • cusc_edx_api/apps.py → CuscEdxApiConfig (plugin_app)
    • cusc_edx_api/models.py → EcommerceOrder
    • cusc_edx_api/views.py → các API view (ping, user lookup, order…)
    • cusc_edx_api/urls.py → URL nội bộ app
    • cusc_edx_api/lms_root_urls.py → dùng làm ROOT_URLCONF
    • cusc_edx_api/management/commands/cleanup_cusc_orders.py → lệnh dọn order

    3) Tích hợp trong môi trường Dev (tutor dev)

    3.1) Mount source plugin vào container LMS

    Giả sử source plugin nằm ở host: /home/dev/projects/cusc_edx_api. Mount vào container, ví dụ /mnt/cusc_edx_api để có thể pip install -e ..

    3.2) Cài plugin vào Python env của LMS (dev)

    tutor dev run lms bash

# Kiểm tra import & entrypoint
a=/openedx/venv/bin/python
$a -c "import cusc_edx_api, pkg_resources; \
print('OK import:', cusc_edx_api.__file__); \

    3.3) Thêm vào INSTALLED_APPS và đổi ROOT_URLCONF (DEV)

    ROOT="$(tutor config printroot)"
cd "$ROOT/env/apps/openedx/settings/lms"
    # Mở development.py và thêm cuối file:
EXTRA_APPS_PATH = "/mnt/cusc_edx_api"  # path trong container
if EXTRA_APPS_PATH not in sys.path:
    sys.path.append(EXTRA_APPS_PATH)

INSTALLED_APPS += ("cusc_edx_api",)
ROOT_URLCONF = "cusc_edx_api.lms_root_urls"

    Giải thích: INSTALLED_APPS giúp Django load app; ROOT_URLCONF trỏ sang router của plugin (plugin sẽ include URL mặc định LMS và chèn thêm URL của mình).

    4) Các API chính (tóm tắt)

    4.1) /api/cusc-edx-api/ping/

    • METHOD: GET — Health check.
    {
  "ok": true,
  "app": "cusc_edx_api"
}

    4.2) API lấy user theo username/email

    # Ví dụ
GET /api/cusc-edx-api/users/lookup/?username=abc
GET /api/cusc-edx-api/users/lookup/?email=abc@example.com

# JSON trả về
{
  "id": 123,
  "username": "abc",
  "email": "abc@example.com",
  "is_active": true
}

    4.3) Model EcommerceOrder

    • Bảng: cusc_ecommerce_order
    • Trường: user (FK), course_id, external_order_id (nullable), amount, currency (mặc định VND), status (pending|paid|failed|canceled|refunded|expired), extra_data (JSONField), created_at, updated_at, expired_at.
    • to_dict() để serialize JSON.

    4.4) API tạo order và cập nhật trạng thái

    # Tạo order (Node.js gọi)
POST /api/cusc-edx-api/orders/
{
  "username": "abc",
  "course_id": "course-v1:org+code+run",
  "amount": "500000",
  "currency": "VND",
  "external_order_id": "NODE_ORDER_123",
  "extra_data": { }
}
# → Trả về JSON có id order LMS, status=pending

# Cập nhật trạng thái thanh toán
POST /api/cusc-edx-api/orders/<order_id>/status/
Headers:
  X-CUSC-PAYMENT-TOKEN: <shared-secret>
Body:
{
  "status": "paid",
  "payment_info": { "gateway": "vnpay", "txn_id": "TXN123456" }
}
# Sau khi paid: enroll user vào course + lưu payment_info

    5) Lệnh dọn order pending (cleanup_cusc_orders)

    5.1) Management command

    File: cusc_edx_api/management/commands/cleanup_cusc_orders.py

    • Tìm order status=pending quá ttl_seconds.
    • --delete: xóa hẳn; nếu không, đánh dấu expired và set expired_at=now.
    # Migrate đảm bảo có command
tutor dev run lms ./manage.py lms migrate cusc_edx_api
# Đánh dấu expired
tutor dev run lms ./manage.py lms cleanup_cusc_orders --ttl-seconds 600
# Xóa hẳn
tutor dev run lms ./manage.py lms cleanup_cusc_orders --ttl-seconds 600 --delete

    5.2) Gợi ý cron (prod)

    */15 * * * * tutor local run lms ./manage.py lms cleanup_cusc_orders \
  --ttl-seconds 3600 --delete >> /var/log/cusc_cleanup.log 2>&1
