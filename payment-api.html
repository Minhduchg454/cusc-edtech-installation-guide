    cusc_edx_api — HƯỚNG DẪN CÁC API ECOMMERCE

    Bản HTML hoá từ tài liệu TXT. Giữ nguyên endpoint và mẫu JSON/cURL để tích hợp nhanh với dịch vụ thanh toán (Node.js).

    BASE URL CHUNG

    Tất cả endpoint đều nằm dưới namespace:

    /api/cusc-edx-api/

    Ví dụ khi chạy local:

    http://localhost:8000/api/cusc-edx-api/...

    1) AUTH GIỮA NODE.JS VÀ LMS

    Gần như mọi API dùng cùng cơ chế bảo vệ bằng header:

    X-CUSC-PAYMENT-TOKEN: <secret>

    <secret> được cấu hình trong Hướng dẫn cài đặt cusc_edx_config

    CUSC_PAYMENT_API_TOKEN = "chuoi-bi-mat-nao-do"
    • Nếu CUSC_PAYMENT_API_TOKEN KHÔNG được set ⇒ các endpoint cho qua (chế độ DEV).
    • Nếu đã set ⇒ request thiếu header/ sai token sẽ trả 401 với body {"error":"Unauthorized"}.

    2) ENDPOINT PING

    Mục đích: kiểm tra app đã load và URL mount đúng.

    GET /api/cusc-edx-api/ping/

    Không yêu cầu token.

    curl http://localhost:8000/api/cusc-edx-api/ping/
# 200 OK
# {"ok": true, "app": "cusc_edx_api"}

    3) TẠO ORDER TỪ NODE.JS

    POST /api/cusc-edx-api/orders/create/

    Yêu cầu: Header token (nếu server có cấu hình) và Body JSON.

    {
  "course_id": "course-v1:ORG+CODE+RUN",
  "amount": 1200000,
  "currency": "VND",                // optional, default "VND"
  "external_order_id": "ABC123",    // optional: id bên Node
  "extra_data": { },                 // optional: thông tin thêm
  "user_id": 5                       // hoặc dùng username / email
  // "username": "student01"
  // "email": "sv@cusc.ctu.edu.vn"
}
    • Phải truyền ít nhất 1 trong 3: user_id | username | email.
    • amount có thể là số hoặc string (server tự convert sang Decimal).
    • Thiếu course_id hoặc amount ⇒ 400.
    curl -X POST http://localhost:8000/api/cusc-edx-api/orders/create/ \
  -H "Content-Type: application/json" \
  -H "X-CUSC-PAYMENT-TOKEN: your-secret-token" \
  -d '{
    "course_id": "course-v1:CTU+CT100+2025_T3",
    "amount": 1200000,
    "currency": "VND",
    "external_order_id": "NODE-ORDER-123",
    "username": "student01"
  }'

    4) XEM CHI TIẾT MỘT ORDER

    GET /api/cusc-edx-api/orders/<order_id>/

    Trả về JSON chi tiết (tương tự lúc tạo). 404 nếu không tồn tại.

    5) LIST ORDER + FILTER

    GET /api/cusc-edx-api/orders/?status=pending&username=student01

    Query params optional: status (pending|paid|failed|canceled|refunded), user_id, username, external_order_id. Server giới hạn tối đa 50 bản ghi.

    6) NODE.JS BÁO TRẠNG THÁI THANH TOÁN

    POST /api/cusc-edx-api/orders/<order_id>/status/

    Body JSON ví dụ (thành công):

    {
  "status": "paid",
  "payment_info": { "gateway": "vnpay", "txn_id": "VNPAY-TXN-12345" }
}
    • Hợp lệ: pending|paid|failed|canceled|refunded.
    • Nếu status=paid: server enroll user vào course (mode=verified) nếu chưa có.

    7) TRA CỨU USER

    GET /api/cusc-edx-api/users/lookup/?username=student01
GET /api/cusc-edx-api/users/lookup/?email=sv@cusc.ctu.edu.vn

    Yêu cầu ít nhất 1 trong 2: username hoặc email. Email so khớp không phân biệt hoa thường.

    {
  "count": 1,
  "results": [
    {
      "id": 1,
      "username": "student01",
      "email": "student01@gmail.com",
      "is_active": true
    }
  ]
}

    8) LẤY PRICING THEO COURSE_ID

    GET /api/cusc-edx-api/course-pricing/<course_id>/?mode=verified

    Ví dụ (giữ nguyên dấu + trong course_id):

    /api/cusc-edx-api/course-pricing/course-v1:CTU+CT100+2025_T3/
/api/cusc-edx-api/course-pricing/course-v1:CTU+CT100+2025_T3/?mode=verified

    Json:

    {
  "course_id": "course-v1:CTU+CT100+2025_T3",
  "modes": [
    {
      "mode_slug": "verified",
      "mode_display_name": "Verified",
      "currency": "vnd",
      "price": "900000",
      "sku": null,
      "bulk_sku": null,
      "expiration_datetime": null,
      "expiration_date": null,
      "is_active": null
    }
  ]
}

    Gợi ý phía Node.js: khi ghép vào URL, dùng encodeURIComponent(courseId), Django sẽ tự decode về đúng chuỗi.

    9) GỢI Ý FLOW TÍCH HỢP NODE.JS

    1. Node nhận yêu cầu → POST /orders/create/ ⇒ tạo order pending, lấy order_id.
    2. Node chuyển hướng người dùng sang cổng thanh toán.
    3. Gateway callback thành công, Node xác thực chữ ký → POST /orders/<order_id>/status/ với {"status":"paid","payment_info":{...}} ⇒ LMS cập nhật order + enroll.
    4. Thanh toán thất bại/hủy → báo failed hoặc canceled.
    5. Để hiển thị giá front-end → GET /course-pricing/<course_id>/?mode=verified.
