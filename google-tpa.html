Đang xem: google-tpa


    Bật đăng nhập Google (Third‑Party Auth) cho Open edX với Tutor

    Tài liệu hướng dẫn end‑to‑end: bật cờ TPA trong Tutor, tạo OAuth Client (Google), cấu hình Provider trong Django Admin, kiểm tra, xử lý lỗi thường gặp và ghi chú bảo mật.

    Mục tiêu

    • Trang đăng nhập có nút Sign in with Google.
    • Người dùng có thể liên kết tài khoản hiện có hoặc đăng ký mới bằng Google.

    Môi trường giả định

    • Tutor chế độ dev (Docker đã cài sẵn).
    • LMS dev: http://local.openedx.io:8000
    • Authn MFE (nếu bật): http://apps.local.openedx.io:1999/authn/login
    • Kiểm tra host dev của bạn:
    tutor config printvalue LMS_HOST
tutor config printvalue CMS_HOST
    Kỳ vọng: 
    local.openedx.io
studio.local.openedx.io

    Nơi lưu plugin

    Thư mục plugin mặc định:

    cd $(tutor plugins printroot)

    Kiến trúc nhanh (nơi phải cấu hình)

    • FEATURES: cần bật ENABLE_THIRD_PARTY_AUTH (khuyến nghị ENABLE_COMBINED_LOGIN_REGISTRATION).
    • THIRD_PARTY_AUTH_BACKENDS: thêm social_core.backends.google.GoogleOAuth2.
    • AUTHENTICATION_BACKENDS: cũng cần nạp backend Google.
    • Secrets: lưu Client secret trong cấu hình server (không lưu trong Admin).
    • Provider Configuration (Django Admin): chứa Client ID, trạng thái Enabled/Visible và gán Site.
    • Sites: gán provider vào site local.openedx.io để nút hiển thị.

    Bước 1 — Tạo Google OAuth Client (Web application)

    1. Consent screen:
      • App name, support email, developer email.
      • Audience: External nếu người ngoài tổ chức có thể đăng nhập.
      • Scopes: openid, email, profile.
      • Nếu để Testing, thêm email vào Test users.
    2. Tạo OAuth Client (Web application):
      • Authorized redirect URIs:
        • Dev: http://local.openedx.io:8000/auth/complete/google-oauth2/
        • Prod: https://YOUR_LMS_DOMAIN/auth/complete/google-oauth2/
    Ghi lại Client ID và Client Secret.

    Bước 2 — Tạo plugin Tutor: bật cờ, backend & lưu secret an toàn

    2.1) Tạo file plugin

    File: $(tutor plugins printroot)/thirdparty-google.yml

    name: thirdparty-google
version: "1.0.0"

config:
  defaults:
    GOOGLE_OAUTH2_KEY: ""
    GOOGLE_OAUTH2_SECRET: ""

patches:

  openedx-lms-common-settings: |
    FEATURES["ENABLE_THIRD_PARTY_AUTH"] = True
    FEATURES["ENABLE_COMBINED_LOGIN_REGISTRATION"] = True

    THIRD_PARTY_AUTH_BACKENDS = list(set((locals().get("THIRD_PARTY_AUTH_BACKENDS") or []) + [
      "social_core.backends.google.GoogleOAuth2",
    ]))

    AUTHENTICATION_BACKENDS = tuple(list(AUTHENTICATION_BACKENDS) + [
      "social_core.backends.google.GoogleOAuth2",
    ])

    SOCIAL_AUTH_GOOGLE_OAUTH2_KEY = "{{ GOOGLE_OAUTH2_KEY }}"
    SOCIAL_AUTH_GOOGLE_OAUTH2_SECRET = "{{ GOOGLE_OAUTH2_SECRET }}"

  openedx-cms-common-settings: |
    THIRD_PARTY_AUTH_BACKENDS = list(set((locals().get("THIRD_PARTY_AUTH_BACKENDS") or []) + [
      "social_core.backends.google.GoogleOAuth2",
    ]))

    AUTHENTICATION_BACKENDS = tuple(list(AUTHENTICATION_BACKENDS) + [
      "social_core.backends.google.GoogleOAuth2",
    ])

    SOCIAL_AUTH_GOOGLE_OAUTH2_KEY = "{{ GOOGLE_OAUTH2_KEY }}"
    SOCIAL_AUTH_GOOGLE_OAUTH2_SECRET = "{{ GOOGLE_OAUTH2_SECRET }}"

    2.2) Điền Client ID/Secret

    # Điền Client ID/Secret lấy từ Google Cloud
tutor config save --set GOOGLE_OAUTH2_KEY="YOUR_GOOGLE_CLIENT_ID" \
                  --set GOOGLE_OAUTH2_SECRET="YOUR_GOOGLE_CLIENT_SECRET"

    2.3) Áp dụng plugin & kiểm tra

    tutor plugins enable thirdparty-google
# Bảo đảm các cờ FEATURES đã bật
tutor config save --set ENABLE_THIRD_PARTY_AUTH=true --set ENABLE_COMBINED_LOGIN_REGISTRATION=true
# Khởi động lại dịch vụ
tutor dev restart lms

# Kiểm tra trong runtime (container)
tutor dev run lms bash -lc 'python - << "PY"
from django.conf import settings
print("THIRD_PARTY_AUTH_BACKENDS =", getattr(settings, "THIRD_PARTY_AUTH_BACKENDS", None))
print("ENABLE_THIRD_PARTY_AUTH =", settings.FEATURES.get("ENABLE_THIRD_PARTY_AUTH"))
print("ENABLE_COMBINED_LOGIN_REGISTRATION =", settings.FEATURES.get("ENABLE_COMBINED_LOGIN_REGISTRATION"))
PY'
    Kỳ vọng: 
    THIRD_PARTY_AUTH_BACKENDS = ['social_core.backends.google.GoogleOAuth2']
ENABLE_THIRD_PARTY_AUTH = True
ENABLE_COMBINED_LOGIN_REGISTRATION = True

    Bước 3 — Tạo Provider trong Django Admin

    LMS → /admin/third_party_auth/oauth2providerconfig/ → Add

    • Backend name: google-oauth2
    • Client ID: dán từ Google Cloud
    • Secret: dán từ Google Cloud
    • Enabled: ✓
    • Visible: ✓
    • Icon class: fa-google (tùy chọn)
    • Name/Display name: Google (tùy chọn)
    • Slug: google-oauth2 (nếu có)
    • Sites: chọn local.openedx.io
    Đến đây là đã hoàn thành cài đặt đăng nhập bên thứ 3 với Google.
    Có thể về trang login/register để kiểm tra.

    Chính sách đăng ký & liên kết tài khoản

    • Nếu đã có tài khoản → đăng nhập 1 lần để liên kết Google.
    • Cho phép đăng ký mới bằng Google:
      • Trong Provider, bật Send to registration first hoặc Skip registration form.
      • (Tuỳ) Bật Associate by email.
      • Đảm bảo hệ thống cho phép đăng ký công khai:
    tutor dev run lms bash -lc 'python - << "PY"
from django.conf import settings
print("ALLOW_PUBLIC_ACCOUNT_CREATION =", getattr(settings, "ALLOW_PUBLIC_ACCOUNT_CREATION", None))
PY'

    Nếu là False → thêm vào plugin:

    patches:
  openedx-lms-development-settings: |
    ALLOW_PUBLIC_ACCOUNT_CREATION = True

    Kiểm tra & chạy thử

    • Bỏ qua MFE (test nhanh):
    http://local.openedx.io:8000/auth/idp_redirect/google-oauth2?next=/dashboard

    Kết quả đúng: chuyển hướng (302) sang Google (không phải 404).

    • MFE (nếu dùng): bật MFE và kiểm tra nút Google.
    tutor plugins enable mfe
tutor config save
tutor dev restart lms mfe
# Mở http://apps.local.openedx.io:1999/authn/login

    (Tuỳ chọn) CORS/CSRF cho MFE dev:

    patches:
  openedx-lms-development-settings: |
    CORS_ORIGIN_WHITELIST = list(set((CORS_ORIGIN_WHITELIST or []) + [
      "http://apps.local.openedx.io:1999",
    ]))
    CSRF_TRUSTED_ORIGINS = list(set((CSRF_TRUSTED_ORIGINS or []) + [
      "http://apps.local.openedx.io:1999",
    ]))

    Troubleshooting (lỗi thường gặp)

    Triệu chứngNguyên nhânCách xử lý
    404 tại /auth/idp_redirect/google-oauth2 Chưa có Provider, chưa gán Site, hoặc backend name/slug sai Tạo/điều chỉnh Provider, gán Site đúng (xem Bước 3)
    redirect_uri_mismatch Redirect URI trong Google không khớp từng ký tự Dùng đúng mẫu: http://local.openedx.io:8000/auth/complete/google-oauth2/ (đúng dấu / cuối)
    Invalid Origin khi tạo client Dán Redirect URI vào ô Authorized JavaScript origins Origins chỉ là scheme://host[:port]; Redirect URI phải đi vào ô Authorized redirect URIs
    Không thấy nút Google Provider chưa Enabled/Visible, chưa gán Site, hoặc MFE chưa bật Sửa Provider, bật MFE (nếu dùng), refresh
    Đăng nhập xong báo “không có tài khoản liên kết” Chưa cho phép đăng ký mới Bật Send to registration first hoặc Skip registration form; bật ALLOW_PUBLIC_ACCOUNT_CREATION nếu cần
    401/CORS khi MFE gọi API Origin MFE chưa whitelist Thêm CORS/CSRF như phần trên 
    tutor dev logs -f lms

    Bảo mật & vận hành

    • Không commit secrets vào repo.
    • Khi lộ secret → Rotate trong Google Cloud, cập nhật cấu hình và tutor dev restart lms.
    • Tách dev/prod: mỗi môi trường dùng client khác nhau.
    • Client Secret không đặt trong Admin; chỉ Client ID nằm ở Provider.

    Phụ lục — Lệnh kiểm tra nhanh

    # In đường dẫn env đã render
tutor config printroot

# Xem lms.env.yml đã có secrets chưa
grep -n SOCIAL_AUTH "$(tutor config printroot)/env/apps/openedx/config/lms.env.yml"

# Inspect settings trong container
tutor dev run lms bash -lc 'python - << "PY"\nfrom django.conf import settings\nprint("THIRD_PARTY_AUTH_BACKENDS =", getattr(settings, "THIRD_PARTY_AUTH_BACKENDS", None))\nprint("FEATURES =", settings.FEATURES)\nPY'

# Liệt kê Sites & Provider google-oauth2 trong DB
tutor dev run lms bash -lc 'python - << "PY"\nfrom django.contrib.sites.models import Site\nfrom third_party_auth.models import OAuth2ProviderConfig\nprint([ (s.id, s.domain) for s in Site.objects.all() ])\nqs = OAuth2ProviderConfig.objects.filter(backend_name="google-oauth2")\nprint("providers:", qs.count(), [ (p.id, p.enabled, [s.domain for s in p.sites.all()]) for p in qs ])\nPY'
