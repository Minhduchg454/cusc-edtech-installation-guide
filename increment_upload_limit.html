Đang xem: upload-limit-studio


    Hướng dẫn tăng giới hạn dung lượng upload file trong Studio (Tutor Open edX)

    Tài liệu này chuyển từ bản TXT sang HTML, giữ nguyên nội dung kỹ thuật và bổ sung tiêu đề, mục lục, nút copy mã lệnh.

    Mục tiêu

    • Mặc định Studio (CMS) chỉ cho upload file ~100MB.
    • Tăng giới hạn (ví dụ 512MB hoặc 1GB) cho cả:
      1. LMS/CMS (Django settings)
      2. Proxy Caddy (request_body.max_size)

    Giả định

    • Tutor local (v20.x, Indigo) với domain:
      • LMS: http://local.openedx.io
      • Studio: http://studio.local.openedx.io
    • Đã cài Tutor (kiểm tra bằng tutor --version).

    1. Kiểm tra giới hạn hiện tại trong CMS

    tutor local run cms ./manage.py cms shell -c "
from django.conf import settings as s
print('MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB =', getattr(s, 'MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB', 'missing'))
print('UPLOAD_CHUNK_SIZE_IN_MB =', getattr(s, 'UPLOAD_CHUNK_SIZE_IN_MB', 'missing'))
"

    Kết quả mặc định thường thấy:

    MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB = 100
UPLOAD_CHUNK_SIZE_IN_MB = 10

    2. Tăng giới hạn ở CMS (Django settings)

    2.1. Dùng plugin YAML

    1. Tạo file plugin cấu hình (nếu chưa có):
    mkdir -p ~/.local/share/tutor-plugins
nano ~/.local/share/tutor-plugins/override_setting.yml

    Nội dung mẫu (tăng lên 1024MB = 1GB):

    name: override_setting
version: "1.0.0"

patches:
  openedx-cms-production-settings: |
    # Max size của 1 file upload trong Studio
    MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB = 1024

    # Kích thước mỗi chunk upload (không bắt buộc, nhưng nên tăng)
    UPLOAD_CHUNK_SIZE_IN_MB = 50
    1. Bật plugin và render lại cấu hình:
    tutor plugins enable override_setting
tutor config save
    1. Restart CMS & kiểm tra lại:
    tutor local restart cms

tutor local run cms ./manage.py cms shell -c "
from django.conf import settings as s
print('MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB =', s.MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB)
print('UPLOAD_CHUNK_SIZE_IN_MB =', getattr(s, 'UPLOAD_CHUNK_SIZE_IN_MB', 'missing'))
"

    Kỳ vọng:

    MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB = 1024
UPLOAD_CHUNK_SIZE_IN_MB = 50

    3. Tăng giới hạn ở Caddy (Proxy)

    Nếu chỉ tăng ở CMS mà không tăng ở Caddy, trình duyệt có thể báo ERR_CONNECTION_RESET hoặc 413 Payload Too Large; log container caddy có dạng status: 413 cho đường dẫn /assets/....

    3.1. Xác định Caddyfile mà Tutor đang dùng

    ROOT=$(tutor config printroot)
cat "$ROOT/env/apps/caddy/Caddyfile"
grep -n "studio.local.openedx.io" "$ROOT/env/apps/caddy/Caddyfile" -nA12

    Ví dụ block cấu hình Studio:

    studio.local.openedx.io{$default_site_port} {{
    @favicon_matcher {{
        path_regexp ^/favicon.ico$
    }}
    rewrite @favicon_matcher /theming/asset/images/favicon.ico

    import proxy "cms:8000"

    handle_path /* {{
        request_body {{
            max_size 250MB
        }}
    }}
}}

    3.2. Chỉnh tay Caddyfile (cách đơn giản)

    1. Mở file để sửa và tăng lên 1GB (1024MB):
    nano "$ROOT/env/apps/caddy/Caddyfile"

    Trong block studio.local.openedx.io{...}, sửa:

    handle_path /* {{
    request_body {{
        max_size 1024MB
    }}
}}
    1. Lưu file & restart Caddy:
    tutor local restart caddy
    1. Kiểm tra nhanh:
    grep -n "studio.local.openedx.io" "$ROOT/env/apps/caddy/Caddyfile" -nA8
grep -n "max_size" "$ROOT/env/apps/caddy/Caddyfile"

    Kỳ vọng

    studio.local.openedx.io{$default_site_port} {{
    @favicon_matcher {{
        path_regexp ^/favicon.ico$
    }}
    rewrite @favicon_matcher /theming/asset/images/favicon.ico

    import proxy "cms:8000"

    handle_path /* {{
        request_body {{
            max_size 1024MB
        }}
    }}
}}
    Lưu ý khi chỉnh tay Caddyfile: Mỗi lần chạy tutor config save, Tutor có thể render lại file từ template + plugin. Hạn chế sửa tay nếu sau đó sẽ chạy lại lệnh này; hoặc lặp lại thao tác sửa.

    4. Kiểm tra & debug

    4.1. Test upload từ Studio

    1. Vào Studio: http://studio.local.openedx.io
    2. Chọn course cần test → tab Files & Uploads (Files)
    3. Upload file lớn (ví dụ 600MB nếu đã set limit 1GB)

    4.2. Nếu vẫn lỗi – đọc log nhanh

    Mở 2 terminal để xem log Caddy và CMS, sau đó thử upload lại:

    tutor local logs caddy -f
tutor local logs cms -f
    • Nếu log Caddy báo status: 413 ⇒ Giới hạn max_size vẫn nhỏ hơn file.
    • Nếu không có 413 ở Caddy nhưng CMS báo lỗi khác ⇒ xem traceback trong log CMS.

    5. Gợi ý thực tế

    • Không nên cho phép upload file vài GB trực tiếp vào Studio vì ảnh hưởng MongoDB & tốc độ export/import course.
    • Với video lớn:
      • Upload lên object storage (S3, MinIO, ...), hoặc
      • Dùng dịch vụ streaming (YouTube, Vimeo, HLS server), sau đó chỉ nhúng URL trong course.

    Kết luận

    • Để tăng size upload trong Studio, cần chỉnh đồng bộ ở 2 chỗ:
      1. CMS: MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB, UPLOAD_CHUNK_SIZE_IN_MB
      2. Proxy Caddy: request_body.max_size cho host Studio
    • Luôn test lại bằng cách upload file lớn và đọc log nếu có lỗi.
