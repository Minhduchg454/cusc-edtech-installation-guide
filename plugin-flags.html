Đang xem: plugin-flags


    Tutor Open edX — Danh sách plugin & cờ

    Phiên bản: mẫu tổng hợp theo nhóm tính năng. Mỗi mục có: danh sách cờ, tác dụng, hướng dẫn cấu hình (nếu có), và YAML plugin mẫu.

    Lưu ý nhanh: Nhiều cài đặt nằm trong FEATURES[...], một số là setting thường (không thuộc FEATURES), và một số là Waffle flags/switches cấu hình trong Django Admin. Luôn restart lms cms sau khi bật plugin.

    $(tutor plugins printroot) là nơi đặt các file plugin (.yml), để vào thư mục đó thì cần chạy:
    cd $(tutor plugins printroot)

    1) Đăng ký & Tài khoản — feature-accounts-auth.yml

    Quản lý chính sách đăng ký, xóa tài khoản và đăng nhập/SSO (MFE đăng nhập).

    Cờ / SettingÁp dụngMặc định (gợi ý)Tác dụngHướng dẫn cấu hình
    FEATURES['ALLOW_PUBLIC_ACCOUNT_CREATION']LMSTrueCho phép người dùng tự đăng ký.Đặt False nếu chỉ muốn admin tạo tài khoản.
    FEATURES['ENABLE_ACCOUNT_DELETION']LMSTrueXóa tài khoản tự phục vụ.Đảm bảo email backend hoạt động để gửi xác nhận.
    FEATURES['ENABLE_THIRD_PARTY_AUTH']LMS,CMSTrueBật đăng nhập bên thứ ba (SSO).Cần khai báo khóa ứng dụng nhà cung cấp (Google, v.v.).
    FEATURES['ENABLE_REQUIRE_THIRD_PARTY_AUTH']LMSFalseBắt buộc SSO (không cho đăng nhập nội bộ).Chỉ bật khi SSO đã thông suốt cho mọi user.
    FEATURES['ENABLE_LOGIN_MICROFRONTEND']LMSTrueDùng Login/Authn MFE hiện đại.Đảm bảo MFE được deploy (plugin mfe của Tutor).

    YAML plugin mẫu

    name: feature-accounts-auth
version: 0.1.0
patches:
  openedx-lms-production-settings: |
    FEATURES["ALLOW_PUBLIC_ACCOUNT_CREATION"] = True
    FEATURES["ENABLE_ACCOUNT_DELETION"] = True
    FEATURES["ENABLE_THIRD_PARTY_AUTH"] = True
    FEATURES["ENABLE_REQUIRE_THIRD_PARTY_AUTH"] = False
    FEATURES["ENABLE_LOGIN_MICROFRONTEND"] = True
  openedx-cms-production-settings: |
    FEATURES["ENABLE_THIRD_PARTY_AUTH"] = True
  openedx-lms-development-settings: |
    FEATURES["ALLOW_PUBLIC_ACCOUNT_CREATION"] = True
    FEATURES["ENABLE_ACCOUNT_DELETION"] = True
    FEATURES["ENABLE_THIRD_PARTY_AUTH"] = True
    FEATURES["ENABLE_REQUIRE_THIRD_PARTY_AUTH"] = False
    FEATURES["ENABLE_LOGIN_MICROFRONTEND"] = True
  openedx-cms-development-settings: |
    FEATURES["ENABLE_THIRD_PARTY_AUTH"] = True

    Phụ lục

    A. Cách dùng plugin Tutor

    # Bật plugin (có thể chỉ rõ đường dẫn file .yml)
tutor plugins enable ~/.local/share/tutor-plugins/feature-accounts-auth.yml

# Tắt plugin
tutor plugins disable feature-accounts-auth

# Áp dụng thay đổi
# Dev
tutor dev restart lms cms
# Local/Production
tutor local restart lms cms

# Liệt kê plugin
tutor plugins list

# Nếu có thay đổi lớn (dịch vụ MFE, forum...)
# có thể cần re-init các dịch vụ liên quan.

    B. FEATURES vs Waffle

    • FEATURES[...]: bật/tắt ở cấp hệ thống qua file settings (plugin YAML chèn patch).
    • Waffle flags/switches: cấu hình động trong Django Admin (theo người dùng/tỷ lệ/thời gian) — không đặt trong plugin YAML này.
    • Settings thường (không thuộc FEATURES): ví dụ DEFAULT_MOBILE_AVAILABLE, ALLOW_HIDING_DISCUSSION_TAB.

    C. Mẹo & Troubleshooting

    • Nếu gặp lỗi “Missing configuration value” khi bật SSO: thêm client id/secret của nhà cung cấp vào cấu hình Tutor (ví dụ Google OAuth2).
    • Luôn kiểm tra log lms/cms sau khi restart để phát hiện setting không hợp lệ.
    • Một số cờ có thể đổi tên theo bản phát hành. Nếu không nhận diện được, tra cứu release notes rồi cập nhật.
