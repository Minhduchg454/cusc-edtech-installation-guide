Đang xem: Hardware Req

    Yêu cầu phần cứng tối ưu cho Ubuntu 24.04

    Để vận hành Tutor Open edX mượt mà trên máy ảo (VM), việc cấu hình tài nguyên ban đầu là cực kỳ quan trọng nhằm tránh lỗi treo máy khi build images.

    1. Hệ điều hành khuyến nghị

    • OS: Ubuntu 24.04 LTS (Noble Numbat).
    • Kiến trúc: x86_64 (64-bit).

    2. Thông số phần cứng tối thiểu

    Cảnh báo: Open edX là một nền tảng cực kỳ nặng (microservices). Việc cấp thiếu tài nguyên sẽ dẫn đến lỗi Exit Code 137 (Out of Memory).
    Thành phần Mức tối thiểu Lý do
    RAM 8GB Cần thiết để build image openedx-dev và chạy các service MySQL, MongoDB, Elasticsearch cùng lúc.
    Ổ cứng (ROM) 100GB Các Docker Images, Volumes dữ liệu và logs phát sinh rất nhanh trong quá trình phát triển.
    CPU 4 Cores Giúp quá trình compile Sass và chạy migrations nhanh hơn, tránh nghẽn cổ chai.

    3. Kiểm tra thông số hiện tại

    Ông chủ có thể chạy lệnh này trên Terminal để kiểm tra máy ảo của mình đã đạt chuẩn chưa:

    # Kiểm tra RAM
free -h

# Kiểm tra dung lượng ổ cứng
df -h /

# Kiểm tra số nhân CPU
nproc

    4. Lưu ý khi tạo Máy ảo (VirtualBox/VMware)

    • Dynamic Disk: Nên để ổ cứng ở chế độ "Dynamically allocated" nhưng giới hạn tối đa 100GB.
    • Network: Nên dùng Bridge Adapter để máy ảo có IP riêng, dễ dàng map hosts từ máy host.
    • Virtualization: Đảm bảo đã bật VT-x/AMD-V trong BIOS của máy thật.
