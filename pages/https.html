Đang xem: HTTPS Setup

    Cấu hình HTTPS giả lập (Local SSL)

    Hướng dẫn sử dụng mkcert để tạo chứng chỉ SSL nội bộ và cấu hình Tutor "đánh lừa" hệ thống để chạy giao thức HTTPS như server thật.

    1. Cài đặt công cụ hỗ trợ

    Cập nhật hệ thống và cài đặt libnss3-tools để quản lý trust store:

    sudo apt update
sudo apt install libnss3-tools

    2. Cài đặt mkcert

    Tải bản build sẵn từ GitHub, cấp quyền thực thi và đưa vào hệ thống:

    wget -O mkcert https://github.com/FiloSottile/mkcert/releases/download/v1.4.4/mkcert-v1.4.4-linux-amd64
chmod +x mkcert
sudo cp mkcert /usr/local/bin/

# Khởi tạo CA nội bộ
mkcert -install
    Kỳ vọng hiển thị: 
    Created a new local CA 💥
The local CA is now installed in the system trust store! ⚡️

    3. Tạo chứng chỉ cho Domains

    Tạo SSL cho các địa chỉ local cần thiết:

    mkcert local.openedx.io studio.local.openedx.io apps.local.openedx.io localhost 127.0.0.1
    Kết quả: Ông chủ sẽ nhận được 2 file: local.openedx.io+4.pem (Certificate) và local.openedx.io+4-key.pem (Private Key).

    4. Cấu hình "Đánh lừa" Server (HTTPS Trick)

    Chạy lệnh sau để ép Tutor nhận cấu hình HTTPS và Proxy như môi trường Production thực thụ:

    tutor config save --set ENABLE_HTTPS=true --set WEB_PROXY=true

    5. Lấy chứng chỉ từ Ubuntu qua Windows

    Để trình duyệt Windows nhận diện "Ổ khóa xanh", ông chủ phải đưa file Root CA về máy thật.
    1. Copy file từ WSL2 ra Windows: Chạy lệnh sau trong Terminal Ubuntu: 
      cp $(mkcert -CAROOT)/rootCA.pem /mnt/c/Users/$USER/Downloads/rootCA.crt

      File sẽ xuất hiện trong thư mục Downloads của Windows dưới tên rootCA.crt.

    2. Cài đặt vào Windows Trust Store:
      • Chuột phải vào file rootCA.crt -> chọn Install Certificate.
      • Chọn Local Machine -> Next.
      • Chọn Place all certificates in the following store.
      • Nhấn Browse và chọn Trusted Root Certification Authorities.

      Đây là bước quan trọng nhất để trình duyệt tin tưởng chứng chỉ nội bộ.

    3. Hoàn tất: Khởi động lại trình duyệt (Chrome/Edge) và truy cập https://local.openedx.io.
