Đang xem: HTTPS Local

    Hướng dẫn tạo HTTPS Local với mkcert

    Thiết lập chứng chỉ SSL giả lập cho các tên miền local.openedx.io

    1. Tải mkcert và tạo chứng chỉ

    Cài đặt công cụ và tạo chứng chỉ gộp cho tất cả các subdomain của Open edX.

    sudo apt update && sudo apt install mkcert libnss3-tools -y
mkcert -install
mkcert local.openedx.io *.local.openedx.io localhost 127.0.0.1
    Lệnh trên sẽ tạo ra 2 file: local.openedx.io+4.pem (cert) và local.openedx.io+4-key.pem (key).

    2. Đưa chứng chỉ vào mục data

    Di chuyển và đổi tên chứng chỉ vào thư mục quản lý dữ liệu của Tutor.

    mkdir -p /home/duc/.local/share/tutor/data/certs
mv local.openedx.io+4.pem /home/duc/.local/share/tutor/data/certs/cert.pem
mv local.openedx.io+4-key.pem /home/duc/.local/share/tutor/data/certs/key.pem

    3. Sửa file Caddyfile

    Thêm dòng cấu hình tls vào đầu mỗi block tên miền trong cấu hình Caddy.

    nano /home/duc/.local/share/tutor/env/apps/caddy/Caddyfile

    Thêm dòng sau vào đầu tiên bên trong các dấu ngoặc nhọn { }:

    tls /home/duc/.local/share/tutor/data/certs/cert.pem /home/duc/.local/share/tutor/data/certs/key.pem
    Ví dụ cấu hình: 
    local.openedx.io {
    tls /home/duc/.local/share/tutor/data/certs/cert.pem /home/duc/.local/share/tutor/data/certs/key.pem
    reverse_proxy lms:8000
}

    4: Nạp chứng chỉ vào trình duyệt

    Xác thực quyền tin tưởng cho Root CA để trình duyệt không báo lỗi bảo mật (ổ khóa đỏ).

    4.1. Tìm vị trí file Root CA

    Trước tiên, ông chủ cần biết file chứng chỉ gốc đang nằm ở đâu trên máy tính.

    mkcert -CAROOT
    Kỳ vọng kết quả: /home/duc/.local/share/mkcert. File ông chủ cần lấy là rootCA.pem.

    4.2. Cấu hình trên Chrome / Edge / Brave

    Các trình duyệt nhân Chromium cần được nạp thủ công nếu lệnh tự động bị từ chối.

    1. Truy cập đường dẫn: chrome://settings/security
    2. Chọn Manage certificates (Quản lý chứng chỉ) → Authorities (Cơ quan chứng nhận).
    3. Nhấn Import và chọn file rootCA.pem đã tìm thấy ở bước trên.
    Lưu ý quan trọng: Khi bảng thông báo hiện ra, ông chủ bắt buộc phải tích chọn vào ô:
    "Trust this certificate for identifying websites" (Tin tưởng chứng chỉ này để xác định các trang web).

    4.3. Cấu hình trên Firefox

    Firefox không dùng chung danh sách chứng chỉ với hệ thống, nên phải nạp riêng.

    • Mở Settings → Gõ tìm kiếm "Cert" → Chọn View Certificates.
    • Tại tab Authorities, nhấn Import.
    • Chọn file rootCA.pem và tích chọn "Trust this CA to identify websites".

    4.4. Kiểm tra kết quả

    5. Chạy lại dự án local

    Cập nhật file hosts và khởi động lại dịch vụ Caddy.

    Sửa file hosts:

    sudo nano /etc/hosts

    Thêm dòng:

    127.0.0.1 local.openedx.io studio.local.openedx.io preview.local.openedx.io apps.local.openedx.io

    Khởi động lại Caddy:

    tutor local restart caddy
