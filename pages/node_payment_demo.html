🏠 Trang chủ

Đang xem: —

    Cài đặt hệ thống thanh toán demo

    Yêu cầu chung

    Đã cài đặt plugin cusc_edx_config.

    Đã tích hợp và test API ping từ host

    Đã tạo các khóa học mẫu.

    Khởi chạy môi trường dev.

    1. Cài đặt tính phí cho khóa học

    Khỏi chạy tutor ở dev

    tutor dev start

    Vào trình duyệt và đăng nhập vào tài khoản admin theo đường dẫn

    http://local.openedx.io:8000/admin

    Ở giao diện quản lý truy cập mục: course_mode -> coursemode -> add 

     http://local.openedx.io:8000/admin/course_modes/coursemode/add/

    Ở ô nhập Course, nhập id khóa học hoặc click chọn icon 🔍 để tìm khóa học đã có trong hệ thống 

    #vidu
Course: course-v1:HoiDanIT+Y0001+2025_T2

    Ở các ô Mode, Display Name, Price, Currency có thể nhập như mẫu sau 

    #vidu
Mode: Verified
Display Name: Khóa học trả phí
Price: 500000
Currency: VND

    Các ô khác tùy ý nhập.

    Nhấn nút SAVE để tiến hành lưu cài đặt khóa học.

    Kiểm tra khóa học đã kích hoạt bán bằng cách vào trang chủ và xem khóa học đó. Kiểm tra hiển nút "Mua khóa học" là ok.

    2. Cài đặt payment demo

    Mở tab terminal mới và di chuyển đến thư mục để chứa file (hoặc tạo nếu chưa có với lệnh mkdir [đường dẫn thư mục]) 

    cd /home/openedx/dev

    Clone repo về

    git clone https://github.com/NekoNeko6996/node-payment-demo

    Di chuyển vào thư mục và cài đặt các thư viện

    cd node-payment-demo
npm install

    Kiểm tra thiết lập CUSC_CHECKOUT_URL và CUSC_PAYMENT_API_TOKEN

    tutor config printvalue CUSC_CHECKOUT_URL
tutor config printvalue CUSC_PAYMENT_API_TOKEN
    Kỳ vọng hiển thị: 
    openedx@nguyenhuuduc:~/dev$ 
tutor config printvalue CUSC_CHECKOUT_URL
tutor config printvalue CUSC_PAYMENT_API_TOKEN
http://localhost:3000/checkout 
123
    Nếu kết quả không giống có thể thiết lập lại 
    tutor config save \
--set CUSC_CHECKOUT_URL="http://localhost:3000/checkout" \
--set CUSC_PAYMENT_API_TOKEN="123"

    Tạo file .env từ .env.example:

    cp .env.example .env

    Mở .env và chỉnh

    nano .env

    Dán nội dung vào (lưu ý khớp với port của CUSC_CHECKOUT_URL và CUSC_PAYMENT_API_TOKEN ở trên) 

    LMS_BASE=http://local.openedx.io:8000
CUSC_PAYMENT_API_TOKEN=123
COURSE_MODE=verified
PORT=3000
    Lưu ý: nếu trong LMS bạn chưa set CUSC_PAYMENT_API_TOKEN, thì Node vẫn gửi header nhưng phía LMS sẽ bỏ qua (chế độ DEV). Khi đưa lên môi trường thật, bắt buộc phải đặt secret mạnh và giống nhau ở cả Node và LMS.

    3. Chạy demo

    Tiến hành khởi chạy

    npm start

    Server sẽ chạy ở http://localhost:3000.

    Có thể test nhanh bằng cách mở tab terminal mới và chạy lệnh

    curl http://localhost:3000/

    Nếu thấy "Node payment demo is running..." là OK.

    4. Kiểm thử mua khóa học

    Đảm bảo đã khởi chạy tutor ở môi trường dev và khởi chạy node_payment_demo.

    Mở trình duyệt và vào trang chủ.

    http://local.openedx.io:8000/

    Đăng nhập vào hệ thống và chọn một khóa học có tính phí (đã thiết lập trước đó).

    Bấm nút "Mua khóa học này".

    Hệ thống chuyển sang cổng 3000 và báo mua khóa học thành công.
