    Tích hợp dịch vụ thanh toán

    Dịch vụ thanh toán độc lập dùng để tích hợp các cổng thanh toán bên ngoài với Open edX (Tutor).
    Hệ thống bao gồm backend Node.js và frontend React, giao tiếp với LMS thông qua API để tạo đơn hàng, xử lý thanh toán và ghi danh người học sau khi giao dịch thành công.

    Tính năng

    • Tạo và quản lý đơn thanh toán cho Open edX.
    • Hỗ trợ các cổng thanh toán (môi trường Sandbox):
      • VNPay
      • PayPal
      • MoMo
    • Tự động cập nhật trạng thái đơn hàng và ghi danh khóa học sau khi thanh toán thành công.
    • Giao diện checkout đơn giản, dễ mở rộng.
    • Phù hợp cho môi trường phát triển, demo và nghiên cứu.
    • Gửi mail thông báo thông tin thanh toán và ghi danh khóa học.

    Luồng thanh toán

    1. LMS chuyển hướng người dùng sang trang checkout
    2. Frontend gửi yêu cầu tới backend để:
      • Tạo đơn hàng trong Open edX
      • Khởi tạo thanh toán với cổng được chọn
    3. Người dùng hoàn tất thanh toán trên cổng bên thứ ba
    4. Backend xử lý callback return/IPN
    5. Đơn hàng được đánh dấu đã thanh toán và người học được ghi danh vào khóa học
    6. Hệ thống gửi mail thông báo đến người dùng.

    Cấu trúc dự án

    openedx-payment-service/
├── backend/   (dịch vụ thanh toán Node.js)
├── frontend/  (giao diện checkout React)
└── README.md

    Yêu cầu

    • Node.js ≥ 18
    • npm
    • Tutor (Open edX Devstack)
    • Đã cài plugin cusc_edx_config
    • Đã tích hợp API và xác minh kết nối thành công thông qua host ping với plugin cusc_edx_config.

    Cài đặt

    0. Clone repo

    Tạo thư mục chứa mã nguồn

    cd /home/openedx/dev

    Clone mã nguồn từ GitHub

    git clone https://github.com/Minhduchg454/openedx-payment-service.git

    1. Cài đặt thư viện

    Backend

    cd backend
npm i

    Frontend

    cd frontend
npm i

    2. Cấu hình Backend

    Tài khoản Sandbox & thông tin xác thực

    Dự án này sử dụng môi trường sandbox cho tất cả các cổng thanh toán được hỗ trợ.
    Bạn phải tạo tài khoản developer/test cho từng nhà cung cấp để lấy các thông tin xác thực cần thiết.

    VNPay (sandbox)

    • Đăng ký tài khoản merchant sandbox tại:
      • https://sandbox.vnpayment.vn/devreg/
    • Sau khi được phê duyệt, VNPay sẽ cung cấp:
      • VNP_TMN_CODE
      • VNP_HASH_SECRET
    • Endpoint thanh toán sandbox đã được cấu hình sẵn

    MoMo (sandbox)

    • Mở repository git:
      • https://github.com/momo-wallet/payment/blob/master/nodejs/CollectionLink.js
    • Lấy thông tin xác thực:
      • MOMO_PARTNER_CODE
      • MOMO_ACCESS_KEY
      • MOMO_SECRET_KEY

    PayPal (sandbox)

    • Tạo tài khoản PayPal developer tại
      • https://developer.paypal.com/home/
    • Tạo thông tin xác thực Sandbox REST API:
      • PAYPAL_CLIENT_ID
      • PAYPAL_CLIENT_SECRET
    • Sandbox của PayPal hỗ trợ đầy đủ luồng thanh toán mà không yêu cầu pháp nhân doanh nghiệp.
    Kiểm tra API Token hiện tại

    Trước khi cấu hình CUSC_PAYMENT_API_TOKEN, cần kiểm tra giá trị token hiện tại trong cấu hình Tutor.

    Thực hiện lệnh sau trong terminal:

    tutor config printvalue CUSC_PAYMENT_API_TOKEN

    Nếu hệ thống đã được cấu hình trước đó, lệnh sẽ trả về giá trị token hiện tại (Hiện tại là 123).

    Trường hợp chưa có giá trị, bạn có thể tự đặt một token bí mật (ví dụ: chuỗi ngẫu nhiên dài tối thiểu 16 ký tự) và đảm bảo:

    • Giá trị trong .env của backend trùng khớp.
    • Giá trị cấu hình trong Tutor trùng khớp.

    Biến môi trường

    Tạo file môi trường .env

    cd backend
nano .env

    Điền nội dung vào file

    # Server
PORT=3000

# Open edX LMS base URL
LMS_BASE=http://local.openedx.io:8000

# Shared secret giữa LMS và Payment Service
CUSC_PAYMENT_API_TOKEN=123

# Default course mode
COURSE_MODE=verified

# ======================
# VNPay (Sandbox)
# ======================
VNP_TMN_CODE=
VNP_HASH_SECRET=
VNP_URL=https://sandbox.vnpayment.vn/paymentv2/vpcpay.html

# Callback URLs
# Khi test local, dùng ngrok:
#   ngrok http 3000
CLIENT_URL=http://localhost:3000
VNP_RETURN_URL=http://localhost:3000/vnpay_return
VNP_IPN_URL=http://localhost:3000/vnpay_ipn

# ======================
# PayPal (Sandbox)
# ======================
PAYPAL_CLIENT_ID=
PAYPAL_CLIENT_SECRET=

# ======================
# MoMo (Sandbox)
# ======================
MOMO_PARTNER_CODE=MOMO
MOMO_ACCESS_KEY=
MOMO_SECRET_KEY=
    ⚠️ Không commit file .env lên repository.

    3. Cấu hình Mail

    3.1 Lấy App Password cho tài khoản hệ thống

    Hệ thống sử dụng Gmail SMTP để gửi email thông báo đơn hàng và ghi danh khóa học.

    Để xác thực, cần tạo App Password (mật khẩu ứng dụng).

    1. Truy cập:
      • https://myaccount.google.com/apppasswords
    2. Đăng nhập tài khoản Google dùng làm email hệ thống.
    3. Tạo mã đăng nhập mới (App Password).
    4. Google sẽ cung cấp mã gồm 16 ký tự.
    5. Sau khi lấy mã, xóa toàn bộ khoảng trắng nếu có trước khi sử dụng.
    ⚠️ Tài khoản phải bật xác minh 2 bước (2-Step Verification) mới tạo được App Password.

    3.2 Cấu hình SMTP cho Tutor (Open edX)

    Ví dụ cấu hình với tài khoản: taolink14@gmail.com

    Thực hiện lệnh sau trên terminal:

    tutor config save \
  --set SMTP_HOST=smtp.gmail.com \
  --set SMTP_PORT=587 \
  --set SMTP_USE_TLS=true \
  --set SMTP_USERNAME=taolink14@gmail.com \
  --set SMTP_PASSWORD=APP_PASSWORD_CUA_BAN \
  --set DEFAULT_FROM_EMAIL="Open edX <taolink14@gmail.com>" \
  --set CONTACT_EMAIL=taolink14@gmail.com

    Sau đó áp dụng cấu hình:

    tutor dev restart

    3.3 Kiểm tra môi trường Dev

    Kiểm tra kết nối plugin
    curl -i http://localhost:8000/api/cusc-edx-api/ping/

    Kết quả mong đợi:

    HTTP/1.1 200 OK

    Body trả về:

    { "status": "ok" }
    Kiểm tra API gửi mail

    Người gửi: taolink14@gmail.com

    Người nhận: minhduchg454@gmail.com

    CUSC PAYMENT TOKEN: 123

    curl -i -X POST \
     -H "Host: local.openedx.io" \
     -H "X-CUSC-PAYMENT-TOKEN: 123" \
     -H "Content-Type: application/json" \
     -d '{
       "to": ["minhduchg454@gmail.com"],
       "subject": "Đơn hàng đang chờ xử lý",
       "template": "emails/order_pending.html",
       "context": {"name": "Duc Nguyen"}
     }' \
     http://localhost:8000/api/cusc-edx-api/mailer/send/

    Kết quả mong đợi:

    • Người nhận nhận được email.
    • Log trả về trạng thái:
    HTTP/1.1 200 OK
Content-Type: application/json

    Nếu trả về 200 OK nhưng không nhận được mail:

    • Kiểm tra lại App Password.
    • Đảm bảo đã bật xác minh 2 bước (2FA).
    • Kiểm tra SMTP_USERNAME và DEFAULT_FROM_EMAIL trùng khớp.
    • Xem log LMS:
    tutor dev logs -f lms

    Hướng dẫn vận hành

    1. Build frontend 
      cd frontend
npm run build
    2. Khởi động Open edX (Tutor), mở terminal mới 
      tutor dev start
    3. Đảm bảo LMS truy cập được tại 
      http://local.openedx.io:8000
    4. Khởi động backend thanh toán, mở terminal khác 
      cd backend
npm start
    5. Backend sẽ chạy tại 
      http://localhost:3000
    6. Truy cập trang checkout thông qua redirect từ LMS hoặc URL test được cấu hình trong Open edX
