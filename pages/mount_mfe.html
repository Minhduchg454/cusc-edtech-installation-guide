Đang xem: —

    Hướng dẫn mount giao diện vào openEDX

    Hướng dẫn clone micro-frontend từ repo đã xây dựng sẳn.

    1. Thông tin chung

    OpenEdx cung cấp sẳn các micro-frontend (MFE) giúp tùy biến giao diện. Truy cập vào kho repo của OpenEdx để tìm các MFE sẳn có và các MFE bắt đầu với frontend-app 

    https://github.com/orgs/openedx/repositories?q=frontend-app

    Danh sách các repo đã tùy chỉnh

    - Trang đăng ký/đăng nhập:

      https://github.com/NekoNeko6996/frontend-app-authn

    - Trang thông tin cá nhân (đổi tên thành frontend-app-profile khi clone): 

      https://github.com/NekoNeko6996/frontend-app-profile-1

    - Trang cài đặt thông tin cá nhân (đổi tên thànhfrontend-app-account khi clone): 

      https://github.com/NekoNeko6996/frontend-app-account-1

    - Trang chủ học viên (đã đăng nhập):

      https://github.com/NekoNeko6996/frontend-app-learner-dashboard

    2. Bật plugin MFE

    Kiểm tra danh sách các plugins

    tutor plugins list
    Kỳ vọng: 
    openedx@nguyenhuuduc:~/.local/share/tutor/env/build/openedx/themes$ tutor plugins list
NAME             	STATUS   	VERSION
creator-group    	✅ enabled	0.1.0
cusc_edx_config  	✅ enabled	1.0.0
mfe              	✅ enabled	20.1.0

    Nếu không tìm thấy plugin với tên là mfe. Tiến hành cài đặt plugin này

    2.1. Cài đặt plugin mfe (nếu chưa có)

    tutor plugins install mfe

    Bật plugins

    tutor plugins enable mfe
tutor config save

    Khởi động lại môi trường dev

    tutor dev stop 
tutor dev start

    Lưu ý: plugin mfe của Tutor không cung cấp giao diện hoàn chỉnh, nó chỉ:

    • mở route /authn, /account, /profile, /learning…
    • cấu hình reverse proxy
    • cho phép mount các frontend-app React vào Open edX Giao diện thực tế phải được mount thủ công ở các bước tiếp theo.

    3. Mount giao diện đăng nhập (Micro-Frontend)

    Từ dự án khóa trước đã xây dựng, tiến hành clone và mount lại giao diện đăng nhập đã phát triển.

    3.1. Tạo thư mục làm việc và clone repo

    Tạo thư mục dev-frontend

    mkdir ~/dev-frontend
cd ~/dev-frontend

    Clone repo

    git clone https://github.com/NekoNeko6996/frontend-app-authn
    Lưu ý: Nếu repo có hậu tố số (ví dụ: frontend-app-authn-1) thì cần clone và đổi tên thư mục như sau: 
    git clone https://github.com/NekoNeko6996/frontend-app-authn-1 ./frontend-app-authn

    3.2. Cài đặt dependencies

    Di chuyển vào thư mục micro-frontend và cài node modules:

    cd frontend-app-authn
npm i

    3.3. Mount micro-frontend vào OpenEdX

    Quay lại thư mục dev-frontend (nếu đang ở trong thư mục con): 

    cd ~/dev-frontend

    Thực hiện mount frontend vào nền tảng Tutor:

    tutor mounts add ./frontend-app-authn

    3.4. Khởi động nền tảng

    tutor dev start

    3.5. Truy cập trang đăng nhập, kiểm tra giao diện

    http://apps.local.openedx.io:1999/authn/login

    Sau khi giao diện thay đổi thành công, tiến hành mount với các repo còn lại.
