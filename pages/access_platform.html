    Hướng dẫn truy cập local web

    1. Kết nối WiFi cán bộ CUSC

    Để truy cập được hệ thống nội bộ, máy client cần kết nối vào mạng WiFi cán bộ của CUSC.

    2. Kiểm tra kết nối đến máy chủ

    Trên máy client windows, mở terminal hoặc cmd chạy

    ping 172.16.160.134

    Kết quả:

    => Đã ping thành công

    3. Thêm cấu hình domain ảo cho host của windows

    Trên windows, truy cập đường dẫn

    C:\Windows\System32\drivers\etc

    Mở file host(file không có đuôi) bằng notepad++(khuyến nghị do cần quyền admin để sửa file host này)

    Thêm vào cuối file host

    # remote IP
172.16.160.134  local.openedx.io  studio.local.openedx.io  apps.local.openedx.io

    => Save lại(yêu cầu quyền admin)

    4. Vào trình duyệt và truy cập

    LMS

    http://local.openedx.io/

    Studio

    http://studio.local.openedx.io/

    MFE

    http://apps.local.openedx.io/

    # Nếu không thành công

    Thử ssh(2 clients) vào máy chủ

    ssh dev@172.16.160.134

    Password

    123

    Ở client đầu tiên chạy

    tutor local start -d

    => Khởi chạy nền tảng

    Ở client thư 2 chạy

    cd ~/node-payment-demo

    Chạy container giả lập thanh toán

    docker run --rm -p 5000:5000 --env-file .env --add-host local.openedx.io:host-gateway node-payment-demo:latest

    Sao đó thử vào trình duyệt và truy cập các link trên

    Nền tảng vẫn đang trong quá trình thử nghiệm, chưa có domain riêng nên các bước setup truy cập từ ngoài sẽ khá phức tạp.
    Nền tảng vẫn có khả năng xuất hiện lỗi.
