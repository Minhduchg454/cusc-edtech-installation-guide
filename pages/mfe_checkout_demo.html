Đang xem: Checkout MFE

    Tạo trang thanh toán khóa học: Checkout MFE

    Hướng dẫn tích hợp Micro-frontend Checkout vào hệ thống Tutor Open edX, hỗ trợ môi trường phát triển (Dev) và vận hành (Prod).

    1. Clone repo và cài đặt thư viện

    Di chuyển đến thư mục làm việc của frontend và tải mã nguồn:

    cd ~/dev-frontend
# Clone repository
git clone https://github.com/Minhduchg454/frontend-app-checkout.git

    Cài đặt các thư viện phụ thuộc

    cd frontend-app-checkout
npm i

    2. Cấu hình cổng thanh toán bên thứ ba

    Mã nguồn mặc định sẽ không đi kèm thông tin cấu hình nhạy cảm. Bạn cần tự tạo file cấu hình local để ứng dụng có thể kết nối với các cổng thanh toán.
    Vui lòng tự khởi tạo dựa trên hướng dẫn bên dưới hoặc liên hệ đơn vị phát triển để xin file cấu hình mẫu nếu có.

    2.1 Tạo file cấu hình

    Di chuyển vào thư mục config và tạo file paymentProviderConfig.js: 

    cd ~/dev-frontend/frontend-app-checkout/src/config
nano paymentProviderConfig.js

    Dán nội dung mẫu bên dưới và thay thế các mã (key) tương ứng của bạn: 

    export const VNPAY_CONFIG = {
  tmnCode: "YOUR_VNPAY_TMN_CODE",
  hashSecret: "YOUR_VNPAY_HASH_SECRET",
  url: "https://sandbox.vnpayment.vn/paymentv2/vpcpay.html",
};

export const MOMO_CONFIG = {
  endpoint: "https://cors-anywhere.herokuapp.com/https://test-payment.momo.vn/v2/gateway/api/create",
  partnerCode: "YOUR_MOMO_PARTNER_CODE",
  accessKey: "YOUR_MOMO_ACCESS_KEY",
  secretKey: "YOUR_MOMO_SECRET_KEY",
};

export const PAYPAL_CONFIG = {
  PAYPAL_CLIENT_ID: "YOUR_PAYPAL_CLIENT_ID",
  PAYPAL_CLIENT_SECRET: "YOUR_PAYPAL_CLIENT_SECRET",
};
    Lưu ý bảo mật: File này chứa thông tin bí mật (Secret Key). Tuyệt đối không commit file này lên các kho lưu trữ công khai (GitHub/GitLab).

    2.2 Hướng dẫn lấy thông tin xác thực (Sandbox)

    Vì dự án sử dụng môi trường thử nghiệm, bạn cần đăng ký tài khoản Developer của từng nhà cung cấp:

    A. VNPay (Sandbox)

    • Đăng ký tài khoản Merchant tại: VNPay DevReg.
    • Sau khi duyệt, bạn sẽ nhận được VNP_TMN_CODE và VNP_HASH_SECRET qua email.

    B. MoMo (Sandbox)

    • Truy cập tài liệu mẫu của MoMo tại: MoMo GitHub Sample.
    • Sao chép các giá trị Test: PARTNER_CODE, ACCESS_KEY, và SECRET_KEY.

    C. PayPal (Sandbox)

    • Truy cập PayPal Developer Dashboard.
    • Vào mục Apps & Credentials, tạo một ứng dụng "REST API" trong môi trường Sandbox để lấy Client ID và Secret.

    3. Mount thư mục vào nền tảng Tutor

    Thực hiện mount để Tutor ưu tiên sử dụng mã nguồn tại máy thay vì trong image: 

    cd ..
tutor mounts add ./frontend-app-checkout

    4. Tạo Plugin khai báo cho Checkout

    Di chuyển đến thư mục chứa các plugins của Tutor:

    cd "$(tutor plugins printroot)"
nano checkout.py

    Dán nội dung cấu hình Python sau vào file:

    from tutormfe.hooks import MFE_APPS
from tutor import hooks

@MFE_APPS.add()
def add_payment_checkout(mfes):
    mfes["checkout"] = {
        "repository": "https://github.com/Minhduchg454/frontend-app-checkout.git",
        "port": 2002,
        "version": "main",
    }
    return mfes

# Cấu hình cho môi trường Production (Common)
hooks.Filters.ENV_PATCHES.add_item(
    (
        "mfe-lms-common-settings",
        """
MFE_CONFIG["PAYMENT_CHECKOUT_URL"] = "http://apps.{{ LMS_HOST }}/checkout/"
"""
    )
)

# Cấu hình cho môi trường Development (Port 2002)
hooks.Filters.ENV_PATCHES.add_item(
    (
        "mfe-lms-development-settings",
        """
MFE_CONFIG["PAYMENT_CHECKOUT_URL"] = "http://apps.{{ LMS_HOST }}:2002/checkout/"
"""
    )
)
    Lưu ý về cấu hình Port:
    • Port 2002 được chọn để tránh xung đột vì các cổng 2000 (Learning) và 2001 (Payment History) đã được sử dụng bởi các MFE trước đó.
    • Giá trị cổng này đã được cấu hình khớp hoàn toàn với nội dung trong file .env của repository frontend-app-checkout, giúp đảm bảo tính đồng bộ khi chạy ở chế độ dev.

    5. Kích hoạt và Build Image

    5.1 Lưu và bật Plugin

    tutor config save
tutor plugins enable checkout

    5.2 Build lại MFE Image

    Việc này giúp đăng ký ứng dụng "checkout" vào trình quản lý MFE tổng quát: 

    tutor images build mfe

    5.3 Build MFE Checkout (Dev)

    tutor images build checkout-dev

    6. Khởi chạy và Kiểm tra

    Khởi động môi trường phát triển:

    tutor dev start
    Thông tin truy cập:
    • URL Dev: http://apps.local.openedx.io:2002/checkout/
    • Đảm bảo rằng LMS đã được cấu hình trỏ đến URL này thông qua plugin.

    7. FAQ nhanh

    • Tại sao chọn port 2002? Để tránh xung đột với các MFE khác (như Learning MFE thường dùng 2000, Payment History dùng 2001).
    • Lỗi 404 khi truy cập? Kiểm tra xem bạn đã chạy tutor config save và restart lại các container chưa.
