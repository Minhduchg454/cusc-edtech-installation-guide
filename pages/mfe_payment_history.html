Đang xem: Payment History MFE

    Tạo trang theo dõi lịch sử thanh toán: Payment History MFE

    Hướng dẫn tích hợp Micro-frontend Lịch sử thanh toán vào hệ thống Tutor Open edX, hỗ trợ theo dõi các giao dịch đã thực hiện.

    1. Clone repo và cài đặt thư viện

    Di chuyển đến thư mục làm việc của frontend và tải mã nguồn:

    cd ~/dev-frontend
# Clone repository
git clone https://github.com/Minhduchg454/frontend-app-payment-history.git

    Cài đặt các thư viện phụ thuộc:

    cd frontend-app-payment-history
npm i

    2. Mount thư mục vào nền tảng Tutor

    Thực hiện mount để Tutor ưu tiên sử dụng mã nguồn tại máy (local development): 

    cd ..
tutor mounts add ./frontend-app-payment-history

    3. Tạo Plugin khai báo cho Payment History

    Di chuyển đến thư mục chứa các plugins của Tutor và tạo file khai báo: 

    cd "$(tutor plugins printroot)"
nano payment_history.py

    Dán nội dung cấu hình Python sau vào file:

    from tutormfe.hooks import MFE_APPS
from tutor import hooks

@MFE_APPS.add()
def add_payment_history(mfes):
    mfes["payment-history"] = {
        "repository": "https://github.com/Minhduchg454/frontend-app-payment-history.git",
        "port": 2003,
    }
    return mfes

# Cấu hình cho môi trường Production (Common)
hooks.Filters.ENV_PATCHES.add_item(
    (
        "mfe-lms-common-settings",
        """
MFE_CONFIG["PAYMENT_HISTORY_URL"] = "http://apps.{{ LMS_HOST }}/payment-history/"
"""
    )
)

# Cấu hình cho môi trường Development (Port 2003)
hooks.Filters.ENV_PATCHES.add_item(
    (
        "mfe-lms-development-settings",
        """
MFE_CONFIG["PAYMENT_HISTORY_URL"] = "http://apps.{{ LMS_HOST }}:2003/payment-history/"
"""
    )
)
    Lưu ý về cấu hình Port & Môi trường:
    • Port 2003 được sử dụng để phân biệt với Learning MFE (2000) và Checkout MFE (2002).
    • Cấu hình này đã được thiết lập khớp hoàn toàn với file .env trong repo, đảm bảo việc kết nối giữa LMS và MFE không bị gián đoạn khi phát triển.

    4. Kích hoạt và Build Image

    4.1 Lưu và bật Plugin

    tutor config save
tutor plugins enable payment_history

    4.2 Build lại MFE Image tổng quát

    Cần thiết để Tutor đăng ký route /payment-history/ vào hệ thống: 

    tutor images build mfe

    4.3 Build MFE Payment History (Dev Mode)

    tutor images build payment_history-dev

    5. Khởi chạy và Kiểm tra

    Khởi động môi trường phát triển:

    tutor dev start
    Thông tin truy cập:
    • URL Dev: http://apps.local.openedx.io:2003/payment-history/

    6. FAQ nhanh

    • Dữ liệu lấy từ đâu? MFE này gọi API từ LMS để lấy danh sách các giao dịch liên quan đến user đang đăng nhập.
    • Lỗi CORS khi chạy Dev? Đảm bảo rằng bạn đã chạy tutor config save sau khi bật plugin để các cấu hình cho phép domain được cập nhật.
