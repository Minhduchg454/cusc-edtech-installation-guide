    Hướng dẫn truy cập các đường dẫn vào Open edX

    1. Môi trường Dev (Tutor dev)

    Khởi chạy môi trường dev

    Yêu cầu:

    • Đã cài đặt tutor
    • Đã khởi chạy môi trường dev

    Khởi động:

    tutor dev start

    Dừng môi trường:

    tutor dev stop

    Các đường dẫn:

    • LMS (Learner – học viên) ~ trang chủ
      http://local.openedx.io:8000/
    • CMS / Studio (quản trị khóa học) ~ dành cho giáo viên, người tạo khóa học
      http://studio.local.openedx.io:8001/
    • Django Admin ~ dành cho quản trị viên hệ thống
      http://local.openedx.io:8000/admin

    Khởi chạy môi trường local

    Yêu cầu:

    • Đã cấu hình Tutor (config.yml)
    • Đã build image Open edX

    Khởi động môi trường local / production:

    tutor local start

    Dừng môi trường:

    tutor local stop

    Các đường dẫn:

    • LMS (Learner – học viên) ~ trang chủ
      https://<LMS_HOST>/
    • CMS / Studio (quản trị khóa học) ~ dành cho giáo viên, người tạo khóa học
      https://<CMS_HOST>/
    • Django Admin ~ dành cho quản trị viên hệ thống
      https://<LMS_HOST>/admin

    Xác định domain và port thực tế

    tutor config printroot

    Các biến thường gặp:

    • LMS_HOST
    • CMS_HOST
    • ENABLE_HTTPS
    • DEFAULT_SITE_DOMAIN

    Kiểm tra route trong môi trường local

    tutor local exec lms python manage.py lms show_urls

    Dùng để xác nhận endpoint tồn tại thực tế (bắt buộc khi debug API, plugin, hoặc routing Nginx).
