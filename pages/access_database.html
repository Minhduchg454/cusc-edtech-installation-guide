Đang xem: CSDL Open edX

    Hướng dẫn xem CSDL Open edX (Tutor)

    Tài liệu này mô tả cách truy cập và kiểm tra cơ sở dữ liệu MySQL của Open edX khi chạy bằng Tutor ở môi trường local.

    Cách 1: Truy cập trực tiếp MySQL qua terminal

    1. Khởi động Tutor

    tutor local start -d

    2. Lấy mật khẩu MySQL root

    tutor config printvalue MYSQL_ROOT_PASSWORD

    Ví dụ kết quả: r2q8wnn1
    (Mật khẩu có thể khác tùy máy)

    3. Truy cập MySQL

    tutor local exec mysql mysql -u root -pr2q8wnn1

    Khi thấy prompt mysql> là đã truy cập thành công.

    4. Hiển thị danh sách CSDL

    SHOW DATABASES;

    5. Truy cập CSDL Open edX

    USE openedx;

    6. Hiển thị các bảng

    SHOW TABLES;

    7. Thao tác với các bảng điển hình:

    Bảng thông tin người dùng

    DESCRIBE auth_user;
SELECT * FROM auth_user;

    Bảng thông tin đơn hàng

    DESCRIBE cusc_ecommerce_order;
SELECT * FROM cusc_ecommerce_order LIMIT 10;

    Cách 2: Truy cập MySQL qua giao diện Web (Adminer)

    1. Khởi động Tutor

    tutor local start

    2. Chạy Adminer

    docker run --network tutor_local_default -p 8080:8080 adminer

    3. Truy cập trình duyệt

    http://localhost:8080/

    4. Thông tin đăng nhập

    Vị trí file config chứa mật khẩu MYSQL_ROOT_PASSWORD:

    nano $(tutor config printroot)/config.yml

    Các thông tin đăng nhập

    • Server: tutor_local-mysql-1
    • Username: root
    • Password: MYSQL_ROOT_PASSWORD
    • Database: openedx

    Các bảng quan trọng trong Open edX

    • student_courseenrollment
      Bảng ghi nhận đăng ký khóa học của người học
    • auth_user
      Bảng thông tin người dùng
    • course_modes_coursemode
      Bảng định nghĩa các chế độ khóa học (free / verified / paid)
