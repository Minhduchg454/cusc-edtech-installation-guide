    Tutor Plugin: cusc_edx_config

    Plugin cấu hình tối giản cho Open edX/Tutor: tăng giới hạn upload ở Studio (CMS) và cung cấp 2 biến cấu hình trên LMS: CUSC_PAYMENT_API_TOKEN (shared secret) và CUSC_CHECKOUT_URL
    (URL trang checkout Node). Không thêm container hay phụ thuộc mới.

    1. Di chuyển đến thư mục chứa cấu hình plugins

    cd ~/.local/share/tutor-plugins/

    Nếu không có file thì dùng lệnh tạo (mkdir -p ~/.local/share/tutor-plugins/)

    2. Điền nội dung file plugin

    Mở file:

     subl cusc_edx_config.yml

    Dán vào nội dung bên dưới:

    name: cusc_edx_config
version: "1.0.0"

config:
  defaults:
    # Mặc định: đổi bằng `tutor config save --set CUSC_CHECKOUT_URL=...`
    CUSC_CHECKOUT_URL: "http://localhost:5000/checkout"
    CUSC_PAYMENT_API_TOKEN: ""

patches:
  # LMS: nhét biến vào cả common/dev/prod (dev là cái bạn đang chạy)
  openedx-lms-common-settings: |
    # CUSC payment token dùng cho Node <-> LMS
    # CUSC_PAYMENT_API_TOKEN = "]lThul5/$PIYVGDTBE;*rRxb3|Lc7o~,dhN;rbY6gpOGO!.ME3:$n+tI4&7HP7;"

    CUSC_PAYMENT_API_TOKEN = "{{ CUSC_PAYMENT_API_TOKEN | default('123456789') }}"

    # === CUSC custom checkout URL for Node service === 
    CUSC_CHECKOUT_URL = "{{ CUSC_CHECKOUT_URL | default('http://localhost:3000/checkout') }}"

  openedx-lms-development-settings: |
    CUSC_CHECKOUT_URL = "{{ CUSC_CHECKOUT_URL | default('http://localhost:3000/checkout') }}"

  openedx-lms-production-settings: |
    CUSC_CHECKOUT_URL = "{{ CUSC_CHECKOUT_URL | default('http://localhost:3000/checkout') }}"

  # (tuỳ chọn) CMS nếu cần
  openedx-cms-production-settings: |
    MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB = 512
    UPLOAD_CHUNK_SIZE_IN_MB = 50
    Giải thích nhanh:
    • CUSC_PAYMENT_API_TOKEN: shared secret để dịch vụ Node.js gọi API nội bộ LMS qua header X-CUSC-PAYMENT-TOKEN.
    • CUSC_CHECKOUT_URL: URL trang thanh toán (Node) để LMS/MFE có thể redirect người học (ví dụ: http://localhost:5000/checkout).
    • MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB & UPLOAD_CHUNK_SIZE_IN_MB: giới hạn upload ở Studio.

    3. Cài đặt plugin vào Tutor

    3.1 Xác định thư mục plugins

    tutor plugins printroot
# ví dụ: ~/.local/share/tutor-plugins

    3.2 Sao chép file vào thư mục đó

    cp ./cusc_edx_config.yml ~/.local/share/tutor-plugins/cusc_edx_config.yml

    3.3 Bật plugin & render lại cấu hình

    tutor plugins enable cusc_edx_config
# render lại templates & patches
tutor config save

    3.4 Thiết lập biến cấu hình (ví dụ DEV)

    Theo yêu cầu Thiết lập URL checkout chạy ở cổng 5000 và đặt token tạm: 

    tutor config save \
  --set CUSC_CHECKOUT_URL="http://localhost:5000/checkout" \
  --set CUSC_PAYMENT_API_TOKEN="123"

    Bạn có thể đổi lại tuỳ môi trường (prod staging...). Nếu không set, giá trị mặc định là http://localhost:3000/checkout.

    3.5 Khởi động lại dịch vụ

    # Local
tutor local restart lms cms

# Dev mode
tutor dev restart lms cms

# Kubernetes
tutor k8s upgrade

    Vì plugin chỉ vá settings, thường không cần build lại image.

    4. Kiểm tra cấu hình đã áp dụng

    4.1 Kiểm tra trên CMS (Studio)

    # MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB
tutor local run cms ./manage.py cms shell -c "from django.conf import settings; print(settings.MAX_ASSET_UPLOAD_FILE_SIZE_IN_MB)"

# UPLOAD_CHUNK_SIZE_IN_MB
tutor local run cms ./manage.py cms shell -c "from django.conf import settings; print(getattr(settings, 'UPLOAD_CHUNK_SIZE_IN_MB', None))"

    4.2 Kiểm tra trên LMS

    # Không in token ra màn hình, chỉ kiểm tra có/không
tutor local run lms ./manage.py lms shell -c "from django.conf import settings; print(bool(getattr(settings, 'CUSC_PAYMENT_API_TOKEN', None)))"

# Xem giá trị CUSC_CHECKOUT_URL hiện tại
tutor local run lms ./manage.py lms shell -c "from django.conf import settings; print(getattr(settings, 'CUSC_CHECKOUT_URL', None))"

    5. Ghi chú & bảo mật

    • Token bảo mật: Không commit token thật lên Git public. Ở production, dùng chuỗi dài, ngẫu nhiên và xoay vòng khi lộ.
    • Quản lý giá trị: config.defaults cung cấp giá trị mặc định. Ghi đè bằng tutor config save --set ... cho từng môi trường.
    • Đọc token từ ENV (tuỳ chọn): Nếu muốn, bạn có thể sửa patch để lấy token từ biến môi trường thay vì hard-code: 
    openedx-lms-common-settings: |
  import os
  CUSC_PAYMENT_API_TOKEN = os.environ.get("CUSC_PAYMENT_API_TOKEN") or "dev-secret"
  # Node.js gửi: X-CUSC-PAYMENT-TOKEN: <token>
    • Đồng bộ token giữa Node.js và LMS (ENV/secret) để request không bị 401.
    • Ở DEV, có thể dùng token ngắn (ví dụ 123) để debug nhanh, sau đó đổi sang chuỗi mạnh hơn.

    6. Proxy/Nginx khuyến nghị (tuỳ chọn)

    Nếu Node checkout chạy cổng 5000 trên cùng máy, có thể reverse-proxy ra subpath/domain ổn định. 

    # NGINX ví dụ
location /checkout/ {
  proxy_pass http://127.0.0.1:5000/checkout/;
  proxy_set_header Host $host;
  proxy_set_header X-Forwarded-Proto $scheme;
  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}

    Giữ CUSC_CHECKOUT_URL trỏ đến URL public tương ứng (vd. https://apps.local.openedx.io/checkout).

    7. Rollback/Gỡ plugin

    tutor plugins disable cusc_edx_config
tutor config save
# Khởi động lại dịch vụ
tutor local restart lms cms

    8. FAQ nhanh

    • Có cần build image? Thường là không. Plugin chỉ vá settings đã render.
    • Áp dụng ở đâu? CMS: giới hạn upload; LMS: CUSC_PAYMENT_API_TOKEN & CUSC_CHECKOUT_URL.
    • Dev vs Prod? Cùng một plugin. Ở Prod nên dùng tutor config save --set ... (hoặc ENV/secret manager) để đặt giá trị riêng.
