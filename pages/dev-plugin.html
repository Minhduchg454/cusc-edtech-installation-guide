    Cài đặt & Gỡ plugin tutor-contrib-dbtest (Tutor Dev)

    Quy trình đầy đủ: bind mã nguồn vào container, cài package ở LMS/CMS, xác nhận entry points & namespace URL; sau đó là kịch bản gỡ sạch.

    1) Cài đặt & chạy thử

    1.1 Clone & inject vào tutor

    # Clone repo từ GitHub:
git clone https://github.com/you/tutor-contrib-dbtest.git ~/tutor-contrib-dbtest

# Inject vào môi trường pipx của tutor (để có lệnh/tập lệnh plugin)
pipx inject tutor -e ~/tutor-contrib-dbtest

    1.2 Bind mã nguồn vào container (dev)

    Mở file override và thêm mount:

    subl ~/.local/share/tutor/env/dev/docker-compose.override.yml

    Nội dung:

    services:
  lms:
    volumes:
      - ~/tutor-contrib-dbtest:/openedx/src/tutor-contrib-dbtest:rw
  cms:
    volumes:
      - ~/tutor-contrib-dbtest:/openedx/src/tutor-contrib-dbtest:rw

    1.3 Recreate containers với override

    docker compose \
  -f ~/.local/share/tutor/env/local/docker-compose.yml \
  -f ~/.local/share/tutor/env/dev/docker-compose.yml \
  -f ~/.local/share/tutor/env/dev/docker-compose.override.yml \
  --project-name tutor_dev up -d --force-recreate lms cms

# (Tuỳ chọn) đảm bảo trạng thái
tutor dev stop lms cms
tutor dev start lms cms

    1.4 Cài plugin vào pip của container

    tutor dev exec lms pip install -e /openedx/src/tutor-contrib-dbtest --no-build-isolation
tutor dev exec cms pip install -e /openedx/src/tutor-contrib-dbtest --no-build-isolation

# Xác nhận đã cài
tutor dev exec lms pip show tutor-contrib-dbtest || echo "NOT INSTALLED in LMS"
tutor dev exec cms pip show tutor-contrib-dbtest || echo "NOT INSTALLED in CMS"

    1.5 Kiểm tra entry points & namespace URL

    # Entry points của gói
tutor dev exec lms python -c "import importlib.metadata as m; d=m.distribution('tutor-contrib-dbtest'); print(d.entry_points)"

# dbui đã có trong namespace URL chưa?
tutor dev exec lms python -c 'import django; django.setup(); from django.urls import get_resolver; print("dbui in namespaces:", "dbui" in get_resolver().namespace_dict)'

# Kiểm tra reverse/resolve cụ thể
tutor dev exec lms ./manage.py lms shell -c '
from django.urls import reverse, resolve
print("reverse:", reverse("dbui:users_page"))
m = resolve("/dbtest/users")
print("resolve:", m.namespace, m.url_name)
'

# Kỳ vọng trả về
# reverse: /dbtest/users
# resolve: dbui users_page

    2) Gỡ plugin (clean uninstall)

    2.1 Gỡ package trong container

    tutor dev exec lms pip uninstall -y tutor-contrib-dbtest || true
tutor dev exec cms pip uninstall -y tutor-contrib-dbtest || true

# Xác nhận đã gỡ
tutor dev exec lms sh -lc 'pip show tutor-contrib-dbtest || echo "NOT INSTALLED in LMS"'
tutor dev exec cms sh -lc 'pip show tutor-contrib-dbtest || echo "NOT INSTALLED in CMS"'

    2.3 Bỏ bind mount mã nguồn (nếu đã mount)

    Mở file override và xoá 2 dòng volumes này:

    subl ~/.local/share/tutor/env/dev/docker-compose.override.yml
    services:
  lms:
    volumes:
      # ❌ xoá dòng này nếu có
      - /home/hoangnam/tutor-contrib-dbtest:/openedx/src/tutor-contrib-dbtest:rw
  cms:
    volumes:
      # ❌ xoá dòng này nếu có
      - /home/hoangnam/tutor-contrib-dbtest:/openedx/src/tutor-contrib-dbtest:rw

    Áp dụng thay đổi bằng recreate containers:

    docker compose \
  -f ~/.local/share/tutor/env/local/docker-compose.yml \
  -f ~/.local/share/tutor/env/dev/docker-compose.yml \
  -f ~/.local/share/tutor/env/dev/docker-compose.override.yml \
  --project-name tutor_dev up -d --force-recreate lms cms

# (Nếu có container riêng tên dbtest)
docker rm -f tutor_dev-dbtest-1 || true

    2.4 Disable plugin ở cấp Tutor & render lại env

    tutor plugins disable dbtest
tutor config save
# Khởi động lại dịch vụ
tutor dev restart lms cms

    2.5 Xác nhận đã sạch trong Django

    # Không còn entry point nào của plugin
tutor dev exec lms python -c 'import importlib.metadata as m; print([e for e in m.entry_points(group="lms.djangoapp") if e.name=="dbui"])'

# Namespace/URL không còn
tutor dev exec lms python -c 'import django; django.setup(); from django.urls import get_resolver; print("dbui in namespaces:", "dbui" in get_resolver().namespace_dict)'

# Endpoint trả 404 (ví dụ)
curl -I http://local.overhang.io:8000/dbtest/users

    2.6 (Tuỳ chọn) Dọn sạch repo local

    rm -rf ~/tutor-contrib-dbtest/{build,dist} \
       ~/tutor-contrib-dbtest/*.egg-info \
       ~/tutor-contrib-dbtest/tutor_contrib_dbtest*.egg-info

    2.7 Gỡ pipx injection

    pipx uninject tutor tutor-contrib-dbtest

tutor config save
tutor dev restart lms cms
